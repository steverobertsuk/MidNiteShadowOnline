Combat Encounter Director v1.0.2 makes it easier to choose the language the mod speaks, adds a reference to every scaling preset, and gives its handouts the same look as its chat replies. Your macros and saved encounters keep working; the only command taken away is `!ced scale damage`, which now explains that damage scaling was removed.

## Change Log

### Added

- **A Language button in the Command Deck.** The Config section of the Command Deck now has a **Language** button, which opens a drop-down of all 24 languages. Beneath it, a table lists every language with its flag, code, English name and native name, as in the other MidNite Shadow mods.
- **A Preset Reference** at the end of the Command Deck (All and Scaling tabs) and the README. Two tables list every party and boss preset, what each changes, and a worked example for a monster with 40 HP and AC 15: Large Party takes it to 56 HP and AC 16, Boss to 120 HP and AC 17. The Command Deck builds its tables from the presets themselves, so they always match.
- The README has a new Languages section, and the language setting is in its configuration table.

### Removed

- **Damage scaling.** The damage percentage never changed anything on the token or in rolls: damage comes from dice and character sheets, which CED can't reach. It was only a number in the status report, and it read as if it had been calculated from the monster's damage. Presets and boss tiers now scale hit points and armour class only. `!ced scale damage`, the Damage % buttons on the Command Deck and the Dmg column of the Status handout are gone, and damage values saved by earlier versions are cleared from tokens and saved encounters when the Mod starts.

### Changed

- **The Command Deck and Status handouts look like CED's chat cards**, with the same card, title bar, buttons and label/value rows.
- The Status handout's tables no longer pick up Roll20's handout table borders and white background.
- Minions now show their hit points as "= 1" in the Status handout, instead of "-999%".

### Fixed

- **Changing the language now rewrites the Command Deck straight away.** Before, `!ced config language` only changed the chat replies, and the Command Deck stayed in the old language until it was next rebuilt.
- **Auto-number Selected now works after Roll20's own Enumerate Tokens.** Roll20's Advanced Transform > Enumerate Tokens numbers duplicate names as "Goblin 3 (1)". Auto-number Selected used to keep the "(1)" and name the tokens "Goblin 3 (1) 1"; now it numbers them cleanly, from "Goblin 1" upwards.

You can still choose the language by typing it, for example:

```
!ced config language fr
```

Chat replies, the Command Deck and the Status handout all switch at once.
